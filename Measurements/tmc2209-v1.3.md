# TMC2209 V1.3 stepper driver

Physical measurements of the actual driver modules used in Radiance3D Version 1,
measured **with the blue heatsink installed**. These values override any generic
StepStick or SilentStepStick dimensions found online.

## Identification

- Component: TMC2209 stepper-driver carrier module (StepStick form factor)
- Manufacturer: BIGTREETECH
- Model or revision: TMC2209 V1.3 (silkscreen `BIGTREETECH TMC2209 V1.3`, visible in `IMG_5233.HEIC`)
- Quantity: 2 (one per axis)
- Measurement source: `Measurements/TMC2209 v1.3/`
- Measured with: digital caliper, IP54, mm mode
- Units: mm

Pinout reference photo: `IMG_5240.HEIC` shows the factory label —
top row `VM GND A2 A1 B2 VDD GND`, bottom row `EN MS1 MS2 PDN CLK STEP DIR`, with
`DIAG INDEX VREF` on the side. This is an identification photo, not a measurement.

## Configuration measured

The heatsink is treated as an installed component, not an accessory. Every dimension
below states explicitly whether it is bare PCB, a heatsink offset, or overall
installed height.

## CAD notes

- **Important protrusions:** the heatsink sets the height above the board and the
  male header pins set the height below it. The 22.24 mm figure is the complete
  envelope and is the number to design the driver bay around.
- **Heatsink is offset, not centred.** The left and right offsets differ by roughly
  1 mm (12.21 vs 11.22), so the driver has a handed orientation inside an enclosure.
  Do not assume a symmetric pocket.
- **Mounting-hole layout:** the StepStick form factor has no mounting holes. These
  modules are retained by their header sockets or by a printed clamp/bay.
- **Connector clearances:** allow finger and screwdriver access to the VREF
  potentiometer and to the MS1/MS2/PDN jumpers; both face the top of the board.
- **Cooling:** the heatsink needs open air above it. A closed pocket at exactly
  22.24 mm will trap heat. Add ventilation or standoff height above the heatsink.
- **Required print clearance:** use a fit-test coupon before committing a driver bay.
  See [`fusion360-parameters.md`](fusion360-parameters.md).
- **Unclear or missing dimensions:** header pin pitch, header row spacing, PCB
  thickness, and heatsink footprint are not measured. See
  [`missing-measurements.md`](missing-measurements.md).
